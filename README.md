# ⚡ AURA Titanium — Open-Core XAUUSD & BTCUSD Quantitative Terminal

**100% Real Walk-Forward Audit · Zero Fake Signals · Live Institutional Pending Order Desk**

AURA Titanium is an open-source quantitative market scanner and walk-forward backtesting engine built for **Gold (`XAUUSD` / `PAXGUSDT`)** and **Bitcoin (`BTCUSD`)**. Every trade in the **Last 100 Trades Ledger** is computed directly against 1,000 real 5-minute historical candles from `data-api.binance.vision` and can be exported to CSV for independent verification on TradingView.

## ✨ Key Capabilities
- **100% Verifiable 100-Trade Audit Ledger:** Inspect exact IST entry/exit timestamps, EMA-20/50 & Bollinger 1.9SD triggers, and candle-by-candle execution (`TP1 @ 0.72x ATR + Auto-BreakEven`).
- **Live Pending Limit Order Desk:** Dynamically calculates institutional pullback `BUY LIMIT` and `SELL LIMIT` zones with built-in position sizing.
- **AI Quant Concierge:** Ask about any historical trade (`#T-001` to `#T-100`) or live pending order.
- **1-Click CSV Audit Export:** Download the entire 100-trade ledger to verify every candle yourself.
